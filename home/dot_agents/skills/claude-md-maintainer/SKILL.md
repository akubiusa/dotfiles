# CLAUDE.md メンテナー

`$claude-md-maintainer [ディレクトリ]`。省略時はカレントディレクトリを対象にする。

1. 対象ディレクトリの存在・可読性を確認し、README、主要なマニフェスト、テスト/ lint スクリプト、レイアウト、既存 `CLAUDE.md` を読む。
2. `references/best-practices.md` を基準に、現行の公式 Claude Code ドキュメントを必要時だけ確認する。ネットワークが使えない場合は静的基準で続行し、その旨を報告する。
3. 既存文書から有効な具体的コマンド、注意事項、構成、チーム規約を抽出し、実際のリポジトリと突き合わせる。存在しないコマンドや古いパスは残さない。
4. 適用可能な主要カテゴリの半数以上が欠ける、構造が壊れている、または実態と異なる記述が複数ある場合は全体を書き直す。それ以外は必要な節だけを更新する。文書がない場合は新規作成する。
5. 本文は既存文書の言語を維持し、新規作成時は英語とする。変更後は方式、根拠、主な変更、検証方法を報告する。

Codex 固有のルールは必要なら `AGENTS.md` にも反映する。両方がある場合は矛盾を作らない。
