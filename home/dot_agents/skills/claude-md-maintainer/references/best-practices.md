# CLAUDE.md best practices

- Keep only repository-specific, actionable instructions.
- State verified build, test, lint, formatting, and deployment commands.
- Describe non-obvious architecture, ownership boundaries, and generated files.
- Put safety constraints and review requirements before workflow details.
- Prefer short sections and links to canonical documents over duplicated policy.
- Remove stale commands and facts; do not add generic advice without a repository-specific action.
